# SPDX License Library

Official license and exception texts from the SPDX License List Data project.

Folders: licenses/ (license texts), exceptions/ (exception texts), metadata/ (source metadata).

INDEX.csv and INDEX.json list entries and download status. MISSING-TEXTS.md records unavailable texts.

Before reusing a license, verify which license actually applies to your project or dependency. Preserve required notices and attribution. This library is not legal advice and does not guarantee compliance.

Refresh: python tools/sync_spdx_licenses.py --output licenses/SPDX
